# PartyHub 🎮

Hub de minijuegos Android para jugar con amigos de forma presencial.

**Asignatura**: Desarrollo de Apps para Dispositivos Móviles — UAM EPS (2025-2026)
**Docente**: Alicia Garrido Peña
**Equipo**: Rafael Romero Monzón · Diego Illescas Lasa

> Para contexto técnico completo (arquitectura, stack, reglas para agentes), ver [`CLAUDE.md`](./CLAUDE.md).

## Juegos

| Juego | Mecánica | Jugadores |
|-------|----------|-----------|
| **The Mind** | Cooperativo: ordenar números 1-100 sin comunicarse | 2-8 |
| **El As** | Baraja española: intercambiar cartas a ciegas, 3 vidas | 3-8 |

**Modos**: Local (un dispositivo) · LAN (cada uno el suyo, sin internet)
