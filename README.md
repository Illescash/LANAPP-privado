## 📱 Descripción de la Aplicación

**PartyHub** es un hub de minijuegos diseñado para jugar con amigos de manera **presencial**. La aplicación ofrece juegos clásicos y divertidos que se pueden disfrutar en reuniones, fiestas o quedadas.

### ✨ Características Principales

- 🎮 **Variedad de juegos** en una sola app
- 📱 **Modo Local**: Un solo teléfono para todos
- 🌐 **Modo LAN**: Cada jugador en su dispositivo, sin internet
- ⚡ **Partidas rápidas**: Diversión inmediata
- 🎯 **Juegos probados**: Basados en clásicos divertidos

### 🎲 Juegos Incluidos

| Juego | Descripción | Jugadores |
|-------|-------------|-----------|
| 🔢 **The Mind** | Sincronización mental: ordenar números sin comunicarse | 2-8 |
| 🃏 **El As** | Baraja española: intercambia cartas y sobrevive | 3-8 |
