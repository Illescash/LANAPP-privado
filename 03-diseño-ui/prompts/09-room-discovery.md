

## Tarea
Diseña una pantalla para buscar y unirse a salas LAN existentes.

## Elementos

1. **UNIÓN DIRECTA**: Input para código de 6 dígitos.
2. **LISTA DE SALAS**:
   - Cards de salas encontradas con: Nombre, Juego, Usuarios (ej 3/8) y calidad de señal.
   - Botón "UNIRSE" en cada card.
3. **EMPTY STATE**: Ilustración y texto si no hay salas cerca.
4. **AVISO SIN WIFI**: Banner de advertencia si el WiFi está apagado.

## Estilo
- Spinner de búsqueda infinito pero elegante.
- Animación de entrada de las nuevas salas detectadas.
